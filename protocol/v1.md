# Sideline 协议 v1

传输：`ws://<host>:17331/v1`，文本帧。一条消息是一个 JSON 对象。`v` 恒为 `1`。未知字段忽略。未知 `type` 回 `unsupported`。

`id` 是 UUID 字符串，`ack` 原样带回。`text` 按 UTF-8 字节计，上限 100000。

## 消息

| 方向 | type | 字段 | 行为 |
|---|---|---|---|
| 手机 → 电脑 | `pair` | `code` | 未持有 token 时的第一条消息 |
| 电脑 → 手机 | `pair_ok` | `token` | 32 字节随机数的十六进制，64 个字符 |
| 手机 → 电脑 | `auth` | `token` | 重连时的第一条消息 |
| 电脑 → 手机 | `auth_ok` | `name` | 通过后可以发送文字 |
| 手机 → 电脑 | `text` | `id` `text` `mode` `enter` | 先注入正文。`enter` 为真时再补一次回车 |
| 电脑 → 手机 | `ack` | `id` `ok` `error` | 每条 `text` 和 `key` 都有一条 ack |
| 手机 → 电脑 | `key` | `id` `key` | 不经过输入法的单独按键 |
| 电脑 → 手机 | `ping` | `t` | 空闲 5 秒时由电脑发出 |
| 手机 → 电脑 | `pong` | `t` | 原样带回。15 秒没有任何入站帧就断开 |
| 手机 → 电脑 | `ping` | `t` | 手机也可以发，电脑回 `pong` |
| 电脑 → 手机 | `kick` | `reason` | 撤销设备后发送，然后关闭连接 |
| 电脑 → 手机 | `error` | `error` | 握手阶段的失败 |

`mode` 是 `paste` 或 `type`。`key` 是 `enter`、`backspace` 或 `escape`。`enter` 缺省为 `false`。

握手完成之前，`text` 和 `key` 回 `error`，错误码 `unauthorized`。`ping` 在握手前后都回 `pong`。

## 错误码

| error | 含义 |
|---|---|
| `bad_code` | 配对码错误或已过期 |
| `bad_token` | token 无效或设备已被撤销 |
| `unauthorized` | 还没有完成配对或鉴权 |
| `busy` | 上一次注入还没结束 |
| `integrity` | 目标窗口以更高权限运行 |
| `empty` | 正文为空，并且不需要补回车 |
| `too_large` | 正文超过 100000 字节 |
| `inject_failed` | 注入失败 |
| `clipboard_race` | 正文已发出，但剪贴板被其他程序改过，没有还原 |
| `unsupported` | 未知的消息类型或模式 |

配对失败不返回剩余次数。同一连接连续 5 次 `bad_code` 后断开。

## 配对

配对码是 6 位数字，由密码学随机数生成。配对窗口打开时展示，60 秒后过期，关闭窗口立即作废。同一时间只有一个有效配对码。

二维码内容是 `sidetype://pair?host=<ip>&port=17331&code=<配对码>&name=<电脑名>`。扫到即可连接，不必再手填配对码。

token 在电脑上只保存 SHA-256。手机保存 token 本身。同一时间只有一条已鉴权的连接，后连上的踢掉先连上的。

夹具在 `protocol/fixtures/`。改本文件必须同时改夹具。
